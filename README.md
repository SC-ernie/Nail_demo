# Liv's Nail Corner — Lowatlas concept demo

A responsive, static nail artist website concept. This is **not an official or client-approved website**.

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## Before publishing
1. Confirm the exact business name, preferred branding, service descriptions, and location.
2. Replace the placeholder Instagram destination (`https://www.instagram.com/`) in `index.html` with the verified artist account.
3. Confirm all prices and booking rules with the artist. Pricing screenshot is shown for reference, not transcribed as authoritative prices.
4. Replace screenshot-based gallery images with approved individual nail photos for a sharper portfolio.
5. Get approval to use images and remove the demo notice only after authorization.
6. Test every link on mobile and desktop and update SEO metadata.

## Files
- `index.html`: content and sections
- `styles.css`: all design styling, grouped by numbered sections
- `script.js`: mobile navigation
- `assets/images/`: original screenshots provided for the concept

No paid backend, framework, or database required.
